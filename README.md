Created by: Matthew Botchek

Made this as a simple experiment to do financial analysis, or rather, test strategies I thought were interesting. 

Two branches exist currently `main` and `feature-AI_Mayhem`

`main`: is the stable branch, with handwritten code and hand created strategies.

`feature-AI_Mayhem`: Is exactly as it sounds like. A branch where I kinda let a local LLM go wild. Wasting tokens just to see what it could do and make. 
This branch is quite buggy and has several longevity issues, though has significantly more content than the `main` branch.
